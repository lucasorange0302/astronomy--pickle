## 실행 방법

1. `astronomy-site` 폴더를 내려받습니다.
2. `index.html`을 더블클릭해 엽니다(크롬·엣지·사파리·삼성 인터넷).
   - `file://`로 열어도 동작하도록 모든 스크립트를 일반 `<script src>`로 불러옵니다. `fetch`·ES module을 쓰지 않습니다.
3. 휴대폰에서는 폴더를 iCloud/드라이브에 올려 브라우저로 열거나, PC에서 연 뒤 화면을 공유하세요.

> 위치 권한(내 위치)은 브라우저·운영체제에 따라 `file://`에서 막힐 수 있습니다.
> 그때는 관측지 목록에서 도시·명소를 고르거나 위경도를 직접 입력하면 됩니다.

> 시간별 구름양(Open-Meteo)과 좌표 기반 실제 하늘 사진(NASA SkyView)은 인터넷이 필요합니다.
> 오프라인이거나 예보 범위 밖이면 각각 "기상 예보 미제공(맑음 기준 추정)", "성도 미리보기"로 자동 폴백하고 오류로 멈추지 않습니다.

## 2026-11-27 업데이트 — 홈 화면 설치(PWA) · 오프라인

### 1) 홈 화면에 앱처럼 설치
- `manifest.webmanifest`: `별너울 · 한국 밤하늘 관측` / `별너울`, `start_url: ./index.html`(자동 라우터가 모바일·데스크톱 판을 고름), `display: standalone`, 배경·테마 `#070b14`.
- 아이콘 3종 — `assets/icons/icon-192.png`(192), `icon-512.png`(512), `apple-touch-icon.png`(180, 불투명).
  - `assets/icons/icon.svg`가 원본이고 `tools/make_icons.py`가 Chromium으로 정확한 픽셀 크기로 렌더링합니다.
  - 밤하늘 `#070b14` 바탕 가운데에 금빛 별자리(연결선 4개)와 은빛→금빛 너울(파도)을 그렸습니다. 모든 그림 요소가 중심 반지름 190px 안에 있어 **maskable 잘라내기(안전 영역 204.8px)** 에서도 잘리지 않습니다.
- HTML 메타(`index.html` → `build.py`가 `mobile.html`·`desktop.html`에도 반영): `manifest`, `apple-touch-icon 180×180`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style=black-translucent`, `apple-mobile-web-app-title=별너울`, `theme-color=#070b14`.
- iOS 홈 화면 앱은 상태 표시줄이 화면을 덮으므로, `display-mode: standalone`에서만 첫 화면·앵커 위치를 `env(safe-area-inset-top)` 만큼 내립니다.

### 2) 서비스 워커 — 오프라인 캐시
- `sw.js`는 `http:`/`https:`에서만 등록되고(`pwa.js`), `file://`로 연 단일 파일판은 등록하지 않습니다.
- **같은 출처의 정적 파일만** 다룹니다. `open-meteo.com`·`images-api.nasa.gov`·`skyview.gsfc.nasa.gov` 등 외부 API·CDN 요청은 `fetch` 핸들러에서 곧바로 `return` 해 브라우저에 그대로 넘깁니다(가로채지 않음).
- 전략: **HTML/JS/CSS/manifest = Network-first**(서버에 먼저 물어보고 실패할 때만 캐시) → 새 배포가 새로고침 한 번에 반영. **이미지(assets/) = Cache-first**(한 번 본 사진은 오프라인에서도).
- `CACHE_NAME`은 `byeolneoul-core-<VERSION>`(현재 `2026-11-27.1`) + `byeolneoul-assets-v1`. 배포 때 `VERSION`을 올리면 install에서 코어 캐시를 새로 받고, activate에서 지난 버전 캐시를 지웁니다. 사진 캐시는 160개로 자동 정리합니다.
- 첫 설치 때 코어 27개 파일(HTML 3 + CSS 3 + JS 17 + manifest + 아이콘 3)을 미리 받아, 비행기 모드에서도 화면과 계산 기능이 뜹니다.

### 3) 설치 안내 — ☰ 더보기 › 📲 앱
- 메뉴 위쪽(화면 버전·화면 공유 다음)에 **📲 앱 → 앱으로 설치** 항목. 상태에 따라 문구가 바뀝니다.
  - 이미 `standalone`으로 실행 중 → **앱으로 실행 중** 배지, 누르면 "이미 앱으로 실행 중입니다" 안내.
  - 방금 설치를 마친 상태(지금 탭은 브라우저 탭) → **설치됨** 배지, "홈 화면의 별너울 아이콘으로 여세요" 안내.
  - Chrome/Edge가 `beforeinstallprompt`를 잡아 둔 경우 → 누르는 즉시 설치 창(`prompt()`).
  - iOS Safari → "Safari 공유(□↑) → 홈 화면에 추가" 4단계 안내 시트. 그 밖의 브라우저는 Chrome(⋮ → 앱 설치)·삼성 인터넷(≡ → 페이지 추가 → 홈 화면)·PC(주소창 설치 아이콘) 안내를 띄웁니다.
- 설치해도 저장한 관측 기록(localStorage)은 그대로이고, 앱을 지우면 함께 지워진다는 점을 시트에 적었습니다.

## 2026-11-27 업데이트 — 2단계 지역 선택 · 사진 5~8장 갤러리 · 모바일 상단 바 제거 · 강수량

### 1) 오늘 밤 — 시·도 → 시·군·구 2단계 지역 선택
- `regions-kr.js`: **16개 시·도 · 230개 시·군·구**의 대표 좌표(시청·군청·구청 소재지)와 인구를 담았습니다.
  - 2026-07-01 시행 행정구역 기준입니다. 광주광역시·전라남도가 **전남광주통합특별시**로 통합(5개 자치구 + 22개 시·군)되고, 인천광역시가 **2군 9구**(제물포·영종·서해·검단구 신설)로 개편된 내용을 반영했습니다. 그래서 시·도는 17개가 아니라 **16개**입니다.
  - 좌표·인구는 Wikidata 행정구역 항목(CC0)에서 받아 `tools/regions_src.json`에 보관하고, `tools/gen_regions_kr.py`로 `regions-kr.js`를 생성합니다.
- **추정 Bortle**: 측정값이 아니라 인구와 도시까지의 거리로 하늘 밝기를 근사한 값입니다(`Σ 인구/(거리+9km)^2.6`). 사이트에 이미 있던 관측지 46곳(도시 26 + 명소 20)의 Bortle 값으로 회귀해 눈금을 맞췄고, 평균 오차는 약 0.5등급입니다.
- UI: 1단계 `시·도`를 고르면 2단계 `시·군·구`가 그 시·도 것만 남습니다(경기도 31개, 전남광주 27개 …). 고르는 즉시 좌표·Bortle·구름·별자리·관측 지수가 갱신됩니다.
- 1단계 마지막 항목 **🏕️ 전국 관측 명소(34곳)** 를 고르면 2단계가 기존 명소 목록(권역별)으로 바뀝니다.
- **📍 내 위치**는 GPS 좌표로 계산하면서 가장 가까운 시·군·구를 찾아 "오산시 근처 · 내 위치"처럼 표시하고, 1·2단계 선택 상자도 그 지역으로 맞춥니다. **위경도 직접 입력**은 그대로입니다.
- 모바일 390px에서 두 셀렉트가 카드 밖으로 나가지 않도록 `min-width: 0; max-width: 100%`를 적용했고, 실측 넘침은 0px입니다.

### 2) 사진 갤러리 — 천체마다 5~8장
- `gallery.js` 하나를 **도감 상세 모달 · 하늘 전체 도감(메시에/NGC) 모달 · 라이브 하늘 정보 시트**가 함께 씁니다.
- 사진 순서: ① `assets/space/` 로컬 사진(photo-sets.js의 천체별 여러 장 + catalog-photos.js 대표 사진) → ② **NASA Image and Video Library**(`images-api.nasa.gov`, CORS 허용)에서 이름·번호로 검색한 관련 사진 → ③ **NASA SkyView** 실제 하늘 탐사 사진(DSS2 적색·청색·적외선, 2MASS-K, WISE 3.4, ROSAT X선).
- 실제로 로드된 사진(`naturalWidth > 0`)만 세고, 중복 URL·깨진 URL은 버립니다. 모두 실패하면 성도 SVG로 대체합니다.
- 1/6 카운터 · 썸네일 · 좌우 화살표 · 손가락 스와이프 · 키보드 ←/→ 를 지원하고, 30분 동안 결과를 캐시합니다.
- **사진 신뢰성 규칙(2026-11-27 보강)** — 실사진만 나오게 아래를 강제합니다.
  - **항성은 NASA 텍스트 검색을 아예 쓰지 않습니다.** `type` 이 비어 있는 라이브 하늘 객체(kind: star)까지 잡도록 이름·Bayer 명칭(α Lyrae)·별 목록(`SKY_DATA.stars`, `catalog-photos.js` 의 `star: true`)으로 판별합니다. 'Vega' 검색이 라스베가스(Vegas)·록히드 베가·베가 로켓을, 'Sirius' 가 위성을, 'Orion' 이 오리온 우주선을 물어 오던 문제 때문입니다.
  - **NASA 결과는 제목+설명+키워드를 모두 검사**합니다. `las vegas`, `artist concept`, `illustration`, `concept`, `artwork`, `diagram`, `chart`, `infographic`, `poster`, `rocket`, `launch`, `spacecraft`, `astronaut`, `crew`, `logo`, `banner`, `rendering`, `simulation`, 도시·미국 지명 등이 하나라도 있으면 버립니다.
  - 천문 근거 단어가 없거나, 천체 이름이 **단어 단위**로 제목(또는 키워드+번호)에 확인되지 않으면 채택하지 않습니다. 본문에 다른 메시에/NGC 번호가 적힌 항목(예: 'Southern Ring Nebula'=NGC 3132)도 제외합니다.
  - 망원경·관측소 촬영 근거(Hubble·Webb·Spitzer·Chandra·ESO·observatory 등)가 있는 항목을 앞에 놓습니다.
  - 2MASS-K 는 기본 스케일에서 새까맣게 나와 빈 사진처럼 보이므로 `Scaling=HistEq` 로 밝기를 폅니다. SkyView 는 한 번 실패 시 한 번 재시도하고, 행성상성운(M57·M27)이 태양계로 오인돼 SkyView 가 빠지던 버그도 고쳤습니다.

### 4) 강수량 — 시간별 구름양 차트와 관측 지수
- Open-Meteo 호출에 `precipitation`(강수량 mm)을 추가해 `cloud_cover, precipitation, precipitation_probability`를 한 번에 받습니다.
- 차트의 각 시간 칸에 **강수량을 파란 막대**로 겹쳐 그렸고, 비·눈이 오는 칸은 💧 표시와 함께 시간 라벨 색이 바뀝니다. 툴팁에는 `22시 · 구름 85% · 강수확률 90% · 강수량 2.1mm`처럼 모두 나옵니다.
- 차트 아래 **☔ 비·눈 예보** 줄에 시간별 강수량·확률을, 패널 하단에 밤 평균 구름·평균 강수확률·밤 합계 강수량을 적었습니다.
- 관측 지수는 한 시간 최고 강수량(`mmMax`)과 평균 강수확률로 추가 감점합니다(강수확률 30%부터, 강수량 0.2mm부터). 예: 같은 조건에서 비 없음 44점 → 3.4mm/시·95% 8점.
- 공유 텍스트와 요약 카드 배지에도 강수 정보가 들어갑니다.

- 조작: 드래그·터치 스와이프, **북/서/천정/동/남** 원탭 버튼, 방위·고도·시야 슬라이더, ＋/－ 줌, 이름·딥스카이 토글.
- 센서: `DeviceOrientationEvent.requestPermission()`(iOS 13+) → `webkitCompassHeading`(없으면 `360 − alpha`)로 방위, `beta·gamma`로 고도(`asin(−cosβ·cosγ)`, ±180 뒤집힘에서도 연속).
- 센서 융합(2026-11-27 수정): 주축은 `devicemotion.rotationRate`의 쿼터니언 적분입니다. **축 이름은 기기 축 기준 — alpha=X(위아래 끄덕임), beta=Y(좌우 돌리기), gamma=Z(화면 비틀기)**. 사파리·크롬 모두 이 규약이라, alpha를 Z축에 넣으면 세로로 든 폰의 위아래 움직임이 '화면 비틀기'로 들어가 고도가 거의 따라오지 않습니다.
- 보정: 방위는 나침반(원형 중앙값·45° 튐 차단), 고도는 중력(beta) 목표를 **같은 상수**로 당깁니다(τ 2.2초, 25°까지 100%·45°에서 0으로 감쇠, 45° 초과는 1.2초 지속 시 재보정). 출력은 데드존 0.25°·저역통과 30ms·최대 300°/s로 방위·고도가 1:1입니다. 고도 범위 −30°~89°.
- HTTPS가 아니거나 권한이 없으면 **정직한 안내 문구**를 띄우고 드래그·버튼으로 대체합니다.
- 별·행성·달·성운을 탭하면 인스펙터 카드(현재 고도·방위·등급·출/남중/몰·해설)가 열리고, **🎯 라이브 뷰로 조준**으로 그 방향에 시선을 맞춥니다.
