# 별너울 — 대한민국 천체관측 가이드

설치·서버·계정 없이 브라우저에서 바로 열리는 정적 천체관측 사이트입니다.
수익화·광고·회원가입 요소는 없습니다.

## 라이브 사이트 (HTTPS, GitHub Pages)

- 메인: https://lucasorange0302.github.io/astronomy--pickle/
- 단일 파일판: https://lucasorange0302.github.io/astronomy--pickle/별너울지도.html
- 저장소(공개): https://github.com/lucasorange0302/astronomy--pickle (브랜치 `main`, 루트)
- HTTPS이므로 아이폰 나침반·자이로 센서(라이브 하늘 모드)가 동작합니다.
- 수정 반영: `astronomy-site/` 파일을 고친 뒤 아래 배포 사본에 복사하고 `git push` 하면 1분 안에 Pages가 다시 빌드됩니다.
  ```bash
  cd astronomy-site && python3 build.py
  cp index.html styles.css *.js README.md 별너울지도.html ../deploy/astronomy--pickle/
  cp -r assets ../deploy/astronomy--pickle/
  cd ../deploy/astronomy--pickle && git add -A && git commit -m "업데이트" && git push
  ```

## 실행 방법

1. `astronomy-site` 폴더를 내려받습니다.
2. `index.html`을 더블클릭해 엽니다(크롬·엣지·사파리·삼성 인터넷).
   - `file://`로 열어도 동작하도록 모든 스크립트를 일반 `<script src>`로 불러옵니다. `fetch`·ES module을 쓰지 않습니다.
3. 휴대폰에서는 폴더를 iCloud/드라이브에 올려 브라우저로 열거나, PC에서 연 뒤 화면을 공유하세요.

> 위치 권한(내 위치)은 브라우저·운영체제에 따라 `file://`에서 막힐 수 있습니다.
> 그때는 관측지 목록에서 도시·명소를 고르거나 위경도를 직접 입력하면 됩니다.

> 시간별 구름양(Open-Meteo)과 좌표 기반 실제 하늘 사진(NASA SkyView)은 인터넷이 필요합니다.
> 오프라인이거나 예보 범위 밖이면 각각 "기상 예보 미제공(맑음 기준 추정)", "성도 미리보기"로 자동 폴백하고 오류로 멈추지 않습니다.

## 기능 전체 목록

### 0. 목차(내비게이션)
- 상단 바에 핵심 4개만 한 줄: **오늘 밤 · 전천 지도 · 라이브 하늘 · 도감** (스크롤 위치에 따라 활성 표시)
- 오른쪽 구석 **☰ 더보기** 드롭다운 — 역할별 그룹으로 정리
  - 관측 계획·현장: 관측 일정(2026~2027) · 전국 관측 명소
  - 도구·자료: 촬영·광학 계산기 · NASA·SpaceX 자료관
  - 입문·학습: 초보자 가이드 & 용어사전 · 용어사전 바로 보기 · 원리 깊이 보기
  - 빠른 실행: 🍪 오늘의 우주 쿠키 · 🤖 AI 천문 도우미
- 항목을 누르면 부드럽게 이동하고 창이 자동으로 닫힘. 모바일 390px에서는 핵심 4개가 헤더 2행에 그대로 보이고, `#constellations`·`#glossary` 같은 기존 앵커도 탭 자동 전환으로 계속 동작합니다.

### 1. 오늘 밤 대시보드
- **관측지**: 전국 26개 도시 + 관측 명소 20곳 + 브라우저 GPS + 위경도 직접 입력
- **날짜/시각**: 날짜 선택, 시각 선택(비우면 "지금"), "지금" 버튼
- **시간별 구름양(Open-Meteo)**: 선택 관측지의 오늘 18시→내일 06시 구름양(%)·강수확률을 받아 **관측 지수에 가중 반영**하고, 13칸 미니 막대 차트로 표시. 맑음/조금/구름 많음/흐림 색 구분, 가장 맑은 시간대 추천. 예보 범위(16일) 밖·오프라인이면 "기상 예보 미제공(맑음 기준 추정)"으로 폴백
- **10초 요약**: 동적 달 위상 SVG, 밝기·월령, 완전히 어두운 시간, 관측 지수(0~100)와 **산출 근거 배지(구름 n% · 달 n% · Bortle n)**, 맨눈 추천 TOP 3, 일몰/박명/월출몰/지방항성시/밤 평균 구름
- **밤 타임라인**: 일몰→시민→항해→천문박명→완전한 어둠 구간과 달이 떠 있는 시간을 시각적으로 표시
- **전천 지도(SVG)**: 별 1,643개(5등급까지 + 별자리 연결선에 쓰인 별), **IAU 별자리 88종 연결선과 이름**, 딥스카이 주요 대상, 행성 7개, 달, 고도 링·방위 눈금
- **달과 태양**: 위상·밝기·월령·거리·현재 고도·월출/월몰, 앞으로 14일 달 위상 스트립, 일출·일몰·3단계 박명
- **행성 표**: 수성~해왕성의 겉보기 등급·고도·방위·시지름·출/남중/몰·관측 가능 배지(좀이/낮음/새벽/초저녁/밤중)
- **시간대별 계획**: 박명이 끝난 뒤부터 새벽까지 매 정시에 가장 잘 보이는 대상 1개
- **이번 달 가장 어두운 밤**: 앞으로 30일 중 관측 지수 상위 3일 + 그 밤으로 바로 이동
- **장비 단계별 추천**: 맨눈/쌍안경/망원경/스마트폰 탭. 지금 고도·최고 고도·달빛 주의·지평선 근처·박명 플래그 표시
- **플랜 복사**: 카카오톡·문자에 붙여넣을 요약 텍스트 생성, 인쇄/PDF 버튼

### 2. 천체 도감 (2,571종) + 별자리 88 — 한 섹션, 두 탭
- **탭 1 · 천체 도감**: 대표 40여 종 카드 + 하늘 전체 도감 2,571종(메시에 110 + 밝은 NGC/IC + 항성·변광성·태양계). 검색·유형·별자리·정렬, 조준 버튼
- **탭 2 · 별자리 88**: IAU 88개 별자리 카드, 계절 필터, 라이브 하늘 조준
- **상세 모달 사진**: 카드를 누르면 상단에 **NASA·허블·제임스웹·탐사선 공개 사진**(M42·M31·M16·M1·M45·행성·달 등 30여 종, 사이트에 내려받아 둔 로컬 파일) 또는 **실제 하늘 탐사 사진(DSS2, NASA SkyView, RA/Dec 좌표 기반)**을 표시. 로딩 스켈레톤 → 실패 시 성도 미리보기로 폴백해 깨진 이미지가 보이지 않음. 사진 출처·원본 링크·레드라이트 필터 적용
- 검색 + 유형(항성·성운·성단·은하·유성우·행성·외계행성) + 장비 + 계절 필터, 정렬 4종, "오늘 밤 뜨는 것만" 토글
- **유성우 5종**(쌍둥이자리·사분의자리·페르세우스·사자자리·오리온자리): 활동 기간·극대까지 남은 날짜·ZHR·모천체·복사점 고도를 계산해 추천에 반영
- 카드에 현재 고도/방위, 달빛 주의, 난이도 표시
- 상세 모달: 좌표(적경/적위)·등급·거리·크기·난이도·필요 장비·최적 시기, **찾는 방법(별자리 길잡이)**, 관측 포인트, **장비별 조견표**, 과학적 배경, **촬영 팁**, 신화, 실전 팁, 원리 접이식
- 행성 7종은 위치를 실시간 계산(카탈로그 고정 좌표 아님)
- 프록시마 센타우리·버나드별·K2-18 b — 한국 관측 가능 여부를 근거와 함께 서술

## 정확도와 한계

- 태양 위치: NOAA 저정밀(오차 ±0.01°). 달·행성: Schlyter 저정밀 궤도 요소(행성 ±1~2′).
  → 행성 위치는 전문 성도 앱과 수십 분각 차이가 날 수 있습니다.
- 일출·일몰·박명·월출·월몰: 2분 간격 고도 표본화 → **±1~2분** 오차. 30일 스캔은 8분 간격(±4분).
- 관측지 좌표는 지도 기반 근사값이며, Bortle 등급은 위성 광공해 추정을 참고한 근사값입니다.
- 구름·미세먼지·기상은 다루지 않습니다(별도 예보 확인 필요).
- 달 위상은 황경차 기반 근사(밝기 오차 수 %), 관측 지수는 경험적 가중치입니다.
- 정밀 계획에는 Stellarium Web, KASI 천문우주정보를 함께 쓰세요.

## 검증 기록

`data.js`·`data-extra.js`·`astro.js`를 JS 엔진(QuickJS)에서 실행하고, `app.js`는 DOM 스텁으로 초기화·상호작용을 실행해 확인했습니다.

- 보름달 2026-12-24 10:28 KST → 밝기 100%, 황경 92.1°, 거리 356,923 km
- 삭 2026-12-09 09:52 KST → 0%, 2027-02-21 08:12 → 100%(반영월식 날)
- 오산 2026-11-26 → 일몰 17:16 / 일출 07:22 / 천문박명 18:47~05:50 (KASI와 일치)
- 2026-12-14 월몰 21:53 (KASI·IMO 자료 21:52와 일치)
- 목성 충 2027-02-11 → −2.6등, 45.2″ / 화성 충 2027-02-20 → −1.2등, 13.8″ / 토성 충 2026-10-04 → 19.7″
- 금성 최대이각 2027-01-03 → 47.0° / 프록시마 최고 고도 −9.9°(한국 관측 불가) / 폴라리스 고도 = 위도
