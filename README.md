- 상태바 자리 불투명 띠(`body::before`)는 라이브 화면에서만 감춥니다(`html[data-screen="live"]`). 다른 화면(오늘 밤·도감·학습관…)은 예전처럼 상태바 아래에서 시작하고 띠도 그대로입니다.

### 1) 낮에 열면 '낮'이라고 말합니다 (정오에 모든 천체가 '박명 중'이던 문제)

- 같은 이유로 추천 카드의 상태 배지도 낮에는 **'낮 하늘'**(기본값 '지금 좋음' 대신)로 바뀝니다.

- 센서: `DeviceOrientationEvent.requestPermission()`(iOS 13+) → `webkitCompassHeading`(없으면 `360 − alpha`)로 방위, `beta·gamma`로 고도(`asin(−cosβ·cosγ)`, ±180 뒤집힘에서도 연속).
- 센서 융합(2026-11-27 수정): 주축은 `devicemotion.rotationRate`의 쿼터니언 적분입니다. **축 이름은 기기 축 기준 — alpha=X(위아래 끄덕임), beta=Y(좌우 돌리기), gamma=Z(화면 비틀기)**. 사파리·크롬 모두 이 규약이라, alpha를 Z축에 넣으면 세로로 든 폰의 위아래 움직임이 '화면 비틀기'로 들어가 고도가 거의 따라오지 않습니다.
- 보정: 방위는 나침반(원형 중앙값·45° 튐 차단), 고도는 중력(beta) 목표를 **같은 상수**로 당깁니다(τ 2.2초, 25°까지 100%·45°에서 0으로 감쇠, 45° 초과는 1.2초 지속 시 재보정). 출력은 데드존 0.25°·저역통과 30ms·최대 300°/s로 방위·고도가 1:1입니다. 고도 범위 −30°~89°.

### 새 기능 — 천체 인스펙터 & 조준
- 전천 지도(SVG)에서도 밝은 별·딥스카이·행성·달·**별자리 연결선**을 탭하면 같은 인스펙터가 열립니다.

### 새 기능 — IAU 별자리 88종
- 별자리 데이터를 19종 → **88종**으로 확장. 한국 위도 33~38°N에서 뜨는 별자리를 빠짐없이 포함합니다.
- 좌표는 공개 카탈로그(d3-celestial의 HYG 기반 J2000 항성 목록), 연결선은 **Stellarium 현대 IAU 별자리 그림**(HIP 번호 기반 843개 구간)을 변환해 넣었습니다. 좌표를 임의로 만들지 않았습니다.
- 별자리마다 한국어/영문 이름·IAU 약자·중요도(rank)·면적 순위(경계 다각형의 구면 면적 계산)·가장 밝은 별·가장 잘 보이는 달·설명을 함께 담았습니다.
- 별자리 이름을 탭하면 인스펙터에 가장 밝은 별, 면적 순위, 잘 보이는 때, 지금 고도가 뜨고 **🎯 라이브 뷰로 조준**이 됩니다.
- **별자리 88 도감**(`#constellations`): 이름·영문·약자 검색, 계절 필터, 카드를 누르면 설명이 열리고 🎯로 라이브 하늘 뷰에서 바로 확인할 수 있습니다.

### 새 기능 — 밤하늘 타임랩스 (하늘 뷰 밀착형)

### 새 기능 — 시야(FOV) 시뮬레이터
