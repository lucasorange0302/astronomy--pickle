# 오늘밤별 — 대한민국 천체관측 가이드

설치·서버·계정 없이 브라우저에서 바로 열리는 정적 천체관측 사이트입니다.
수익화·광고·회원가입 요소는 없습니다.

- 메인: https://lucasorange0302.github.io/astronomy--pickle/
- 단일 파일판: https://lucasorange0302.github.io/astronomy--pickle/별밤지도.html

- 수정 반영: `astronomy-site/` 파일을 고친 뒤 아래 배포 사본에 복사하고 `git push` 하면 1분 안에 Pages가 다시 빌드됩니다.
  ```bash
  cp index.html styles.css data.js data-extra.js astro.js app.js README.md 별밤지도.html ../deploy/astronomy--pickle/
  cd ../deploy/astronomy--pickle && git add -A && git commit -m "업데이트" && git push
  ```

## 실행 방법

1. `astronomy-site` 폴더를 내려받습니다.
2. `index.html`을 더블클릭해 엽니다(크롬·엣지·사파리·삼성 인터넷).
   - `file://`로 열어도 동작하도록 모든 스크립트를 일반 `<script src>`로 불러옵니다. `fetch`·ES module을 쓰지 않습니다.
3. 휴대폰에서는 폴더를 iCloud/드라이브에 올려 브라우저로 열거나, PC에서 연 뒤 화면을 공유하세요.

> 위치 권한(내 위치)은 브라우저·운영체제에 따라 `file://`에서 막힐 수 있습니다.
> 그때는 관측지 목록에서 도시·명소를 고르거나 위경도를 직접 입력하면 됩니다.

## 기능 전체 목록

### 1. 오늘 밤 대시보드
- **관측지**: 전국 26개 도시 + 관측 명소 20곳 + 브라우저 GPS + 위경도 직접 입력
- **날짜/시각**: 날짜 선택, 시각 선택(비우면 "지금"), "지금" 버튼
- **10초 요약**: 동적 달 위상 SVG, 밝기·월령, 완전히 어두운 시간, 관측 지수(0~100), 맨눈 추천 TOP 3, 일몰/박명/월출몰/지방항성시
- **밤 타임라인**: 일몰→시민→항해→천문박명→완전한 어둠 구간과 달이 떠 있는 시간을 시각적으로 표시
- **전천 지도(SVG)**: 밝은 별 143개, 별자리 선 19개와 이름, 딥스카이 주요 대상, 행성 7개, 달, 고도 링·방위 눈금
- **달과 태양**: 위상·밝기·월령·거리·현재 고도·월출/월몰, 앞으로 14일 달 위상 스트립, 일출·일몰·3단계 박명
- **행성 표**: 수성~해왕성의 겉보기 등급·고도·방위·시지름·출/남중/몰·관측 가능 배지(좀이/낮음/새벽/초저녁/밤중)
- **시간대별 계획**: 박명이 끝난 뒤부터 새벽까지 매 정시에 가장 잘 보이는 대상 1개
- **이번 달 가장 어두운 밤**: 앞으로 30일 중 관측 지수 상위 3일 + 그 밤으로 바로 이동
- **장비 단계별 추천**: 맨눈/쌍안경/망원경/스마트폰 탭. 지금 고도·최고 고도·달빛 주의·지평선 근처·박명 플래그 표시
- **플랜 복사**: 카카오톡·문자에 붙여넣을 요약 텍스트 생성, 인쇄/PDF 버튼

### 2. 천체 도감 (48종)
- 검색 + 유형(항성·성운·성단·은하·유성우·행성·외계행성) + 장비 + 계절 필터, 정렬 4종, "오늘 밤 뜨는 것만" 토글
- **유성우 5종**(쌍둥이자리·사분의자리·페르세우스·사자자리·오리온자리): 활동 기간·극대까지 남은 날짜·ZHR·모천체·복사점 고도를 계산해 추천에 반영
- 카드에 현재 고도/방위, 달빛 주의, 난이도 표시
- 상세 모달: 좌표(적경/적위)·등급·거리·크기·난이도·필요 장비·최적 시기, **찾는 방법(별자리 길잡이)**, 관측 포인트, **장비별 조견표**, 과학적 배경, **촬영 팁**, 신화, 실전 팁, 원리 접이식
- 행성 7종은 위치를 실시간 계산(카탈로그 고정 좌표 아님)
- 프록시마 센타우리·버나드별·K2-18 b — 한국 관측 가능 여부를 근거와 함께 서술

### 3. 촬영·계산 랩
- **별 점상 노출**: 500 법칙·NPF 법칙·픽셀 피치·픽셀당 화각·번짐 길이(픽셀), 카메라/센서/화소/적위 입력, **계산 해설과 실패 조건**
- **망원경 광학**: 배율·실시야·사출동공·광속비·한계등급·다우스 한계·집광력·최대 유효 배율·과배율 경고·달 크기 비교, **해설**
- **등급·거리**: m·M·거리(광년/파섹/AU/천광년/백만광년) 상호 계산, 태양 대비 광도, **거리 지수 해설·주의**

### 4. 초보자 가이드
- 7단계 관측 입문, 장비 사다리 4단계
- **스마트폰 은하수·성운 촬영 가이드**(준비물·설정·스태킹·어댑터·실패 이유)
- **적위 한계 계산기**: "내 위치에서 이 천체가 보일까?" — 최고 고도·주극성·불가 판정
- 용어사전 29개(점선 용어 클릭 시 쉬운 풀이 + 상세 설명)

### 5. 전국 관측 명소
- Bortle 1~9 등급 설명과 등급별 관측 가능 대상
- 권역 필터(수도권·강원·영남·호남·충청·제주), 20곳의 해발·좌표·교통·시설·추천 계절·실전 팁
- "현재 관측지에서 가까운 순" 정렬(하버사인 거리)

### 6. 체크리스트 · 관측 로그

## 정확도와 한계

- 태양 위치: NOAA 저정밀(오차 ±0.01°). 달·행성: Schlyter 저정밀 궤도 요소(행성 ±1~2′).
  → 행성 위치는 전문 성도 앱과 수십 분각 차이가 날 수 있습니다.
- 일출·일몰·박명·월출·월몰: 2분 간격 고도 표본화 → **±1~2분** 오차. 30일 스캔은 8분 간격(±4분).
- 관측지 좌표는 지도 기반 근사값이며, Bortle 등급은 위성 광공해 추정을 참고한 근사값입니다.
- 구름·미세먼지·기상은 다루지 않습니다(별도 예보 확인 필요).
- 달 위상은 황경차 기반 근사(밝기 오차 수 %), 관측 지수는 경험적 가중치입니다.
- 정밀 계획에는 Stellarium Web, KASI 천문우주정보를 함께 쓰세요.

## 2026-11-26 업데이트 — 검증본 반영 · 라이브 하늘 뷰 · 단일 파일

### 새 파일: `별밤지도.html`
- `styles.css` + `data.js` + `data-extra.js` + `astro.js` + `app.js`를 인라인 `<style>`·`<script>`로 합친 **단일 HTML**(약 459KB).
- 외부 요청 0건(아이콘도 data URI). 폰이나 PC에서 이 파일만 열면 모든 기능이 동작합니다.
- 인라인 스크립트 안의 `</script>` 문자열은 이스케이프해 HTML 파싱이 깨지지 않게 했습니다.
- 다시 만들 때: `index.html` 등을 수정한 뒤 빌드 스크립트로 재생성(작업 기록 참조).

### 새 기능 — 스텔라리움 라이브 하늘 뷰 (`#live`)
- Canvas에 현재 관측지·시각의 하늘을 실제 방위·고도로 투영(시야 90° 이상은 스테레오그래픽, 그 아래는 노모닉).
- 밝은 별 143개·별자리 선 19개·행성 7개·달(위상)·주요 딥스카이·태양을 그립니다. 태양 고도에 따라 하늘 밝기와 별 보임을 실제처럼 바꿉니다(낮에는 별이 거의 보이지 않음).
- 조작: 드래그·터치 스와이프, **북/서/천정/동/남** 원탭 버튼, 방위·고도·시야 슬라이더, ＋/－ 줌, 이름·딥스카이 토글.
- 센서: `DeviceOrientationEvent.requestPermission()`(iOS 13+) → `webkitCompassHeading`(없으면 `360 − alpha`)로 방위, `beta − 90`으로 고도. 부드럽게 보간해 따라갑니다. HTTPS가 아니거나 권한이 없으면 **정직한 안내 문구**를 띄우고 드래그·버튼으로 대체합니다.
- 별·행성·달·성운을 탭하면 인스펙터 카드(현재 고도·방위·등급·출/남중/몰·해설)가 열리고, **🎯 라이브 뷰로 조준**으로 그 방향에 시선을 맞춥니다.

### 새 기능 — 천체 인스펙터 & 조준
- 전천 지도(SVG)에서도 별 18개·딥스카이·행성·달을 탭하면 같은 인스펙터가 열립니다.
